Hide Enterprise Modules

This module automatically filters out and hides Enterprise-only modules from the Apps menu when running Odoo 19 Community Edition, providing a cleaner and more relevant interface.

Key Features

  • Automatic Detection: Identifies Enterprise modules based on license type (OEEL-1) and to_buy flag
  • Clean Interface: Shows only Community Edition compatible modules in the Apps menu
  • Non-Breaking: Does not interfere with existing functionality or installed modules
  • Transparent: Advanced users can still view Enterprise modules using search filters
  • Safe: Only affects display, not module loading mechanism

How It Works

The module extends the ir.module.module model with a computed field is_enterprise_only that automatically identifies Enterprise modules. The Apps menu is then filtered to hide these modules by default.

Enterprise Module Detection:
A module is considered Enterprise-only if it has license = 'OEEL-1' OR to_buy = True

Installation

  1. This module should already be in your custom/addons directory
  2. Update the Apps list (may require Developer Mode)
  3. Search for "Hide Enterprise Modules"
  4. Click "Activate"

Usage

Once installed, the module works automatically. The Apps menu will only show Community Edition compatible modules.

Advanced users can use the search filters to view Enterprise modules:

  • Community Only: Shows only Community modules (default)
  • Enterprise Only: Shows Enterprise modules for reference

Compatibility

  • Odoo Version: 19.0 Community Edition
  • License: LGPL-3
  • Dependencies: base (core module only)

Support

This is a community module designed to improve the user experience in Odoo Community Edition. It can be safely installed or uninstalled at any time without affecting your data or other modules.
